# 🎬 PKShortClips Studio — AI Short Clip Creator

> แพลตฟอร์มสร้างคลิปสั้น AI สไตล์ภาพยนตร์ไทยย้อนยุค 2530 โดย **PKBABY** ใช้งานฟรี ไม่จำกัด และไม่ต้องเสียเครดิต

---

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **Explore Hub (คลังไอเดีย):** ค้นพบสูตรสร้างคลิปสั้นไวรัล เช่น อนิเมะบ้านทุ่ง, นินจาไร่มันสำปะหลัง, นักรบงานวัด พร้อมปุ่มโหลดเข้าสตูดิโอในคลิกเดียว
2. **AI Image Generation (ใช้งานฟรี ไม่เสียเครดิต):** เชื่อมต่อเอนจิน Flux.1 ผ่านระบบของสตูดิโอ พิมพ์ Prompt แล้วกด **Generate** จะสร้างภาพจริงลงบอร์ดทันที
3. **Turn to Video (สตูดิโอกำกับวิดีโอ):** จำลองการเคลื่อนไหวของกล้องแบบ Pan/Zoom (Ken Burns Effect), ซับไตเติลภาษาไทยตรงตามจังหวะ Beat, และเสียง Optical Sound
4. **Clip & Filter Edit:** ปรับแต่งค่าความสว่าง, คอนทราสต์, Saturation -15, และฟิลเตอร์ฟิล์มโบราณ 16mm พร้อมปุ่มดาวน์โหลดลงเครื่อง
5. **Interactive Audio Engine:** จำลองเสียงพากย์สดในห้องอัดแบบแห้งโมโน พร้อมเสียงซ่า Optical Hiss
6. **Admin Dashboard:** จัดการ เพิ่ม/ลบ/แก้ไข Prompt และดูสถิติได้ในคลิกเดียว

## 🚀 คู่มือขั้นตอนการทดสอบใช้งานจริง (1 2 3)

### ขั้นตอนที่ 1: เข้าใช้งานผ่านเว็บเบราว์เซอร์
เปิดลิงก์: **[http://localhost:5173/](http://localhost:5173/)**

### ขั้นตอนที่ 2: ทดสอบสร้างภาพ AI ใหม่ (ไม่เสียเครดิต)
1. ดูที่แถบด้านล่าง **(Floating Prompt Bar)**
2. พิมพ์คำสั่งที่ต้องการ หรือคลิกเลือกปุ่มชิป เช่น `+ สเต็ป 3: ฉากบ่อปลา (First Frame)`
3. คลิกปุ่มสีเขียวนีออน **`Generate (สร้างจริง)`**
4. ระบบจะเรียกใช้ Flux AI Engine สร้างภาพจริงขึ้นมาบนบอร์ดโดยไม่ต้องใส่ API Key และไม่เสียเครดิตใดๆ

### ขั้นตอนที่ 3: ทดสอบฟังก์ชันเครื่องมือต่างๆ
1. **ดูวิดีโอแบบเต็ม:** คลิกที่การ์ดใดก็ได้ในบอร์ด แล้วกดปุ่มสีเขียว **`Turn to video`** เพื่อดูวิดีโอ 9:16 ที่จำลองการแพนกล้องและซับไตเติลภาษาไทย
2. **แต่งภาพ:** คลิกปุ่ม **`Clip & Filter Edit`** เพื่อปรับฟิลเตอร์ฟิล์มเก่าและกดดาวน์โหลดภาพ
3. **คัดลอก Prompt:** คลิกปุ่ม **`Copy Prompt`** พร้อมเอฟเฟกต์ Confetti
4. **ค้นหาไอเดียใหม่:** คลิกแท็บ **`Explore (คลังไอเดีย)`** ที่เมนูด้านบน แล้วกด **`โหลดสูตรนี้เข้าสตูดิโอ`**
